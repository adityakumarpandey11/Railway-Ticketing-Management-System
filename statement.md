# Railway Ticketing Management System
## Problem Statement

Managing railway ticket bookings manually can be time-consuming and difficult to organize. This project provides a simple Python-based system to manage railway ticket bookings through a console interface.

## Scope of the Project

The project covers basic railway ticket operations such as booking tickets, viewing bookings, searching tickets, cancelling tickets, and managing bookings through an administrator section.

## Target Users
Passengers/Users – To book, view, search, and cancel their tickets.\
Administrators – To view and manage bookings and access railway statistics.

## High-Level Features
- User and administrator login
- Railway ticket booking
- Train selection
- Origin and destination details
- Passenger information
- PNR number generation
- View and search tickets
- Ticket cancellation
- Administrator booking management
- Railway statistics
- Menu-driven console interface
